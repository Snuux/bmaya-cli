# bmaya documentation

- [Commands](commands.md): every command with its options, output and exit codes.
- [Sessions, sharing one Maya, start and stop](sessions.md): several Mayas, who owns which undo step, environment variables, screenshots without a window.

- [UVs and textures](uv.md): the layout report, texture fit, the layout picture, comparing layouts, baking position and normal maps.
- [Topology](topology.md): edge loops around tubes, runs of loops, joint places, the loops picture.
- [Skin weights](skin.md): the skin report, weights files, copy, mirror, prune, weight pictures.
- [Skeletons and mirroring](skeleton.md): the bones report, comparing with a game file, new axes, bind pose, rebinding, mirroring a skinned mesh.
- [Animation](animation.md): frame specs, listing and editing clips, motion checks, rig inventory, trails, curve plots, previews.
- [Export](export.md): FBX presets, checks before and after, the Game Exporter, reading a file without Maya, glTF.
- [Troubleshooting](troubleshooting.md): common messages, the crash journal, where state is kept.
